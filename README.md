# 🌐 Proyecto: Ciudadanía Digital

Página web interactiva diseñada para educar sobre la netiqueta, seguridad digital y derechos en la red.

## 🚀 Características
* **Carrusel de imágenes:** Galería interactiva cyberpunk.
* **Buscador en tiempo real:** Filtra temas e información.
* **Quiz interactivo:** Autoevaluación sobre Netiqueta.

## 🛠️ Tecnologías utilizadas
* HTML5
* CSS3
* JavaScript (ES6)
